# 서울의 서재

서울 전자도서관 14곳, 밀리의서재, 은평구 공공도서관의 실물도서를 한 번에 검색하는 웹 도구입니다. Express API와 HTML/CSS/vanilla JS로 구성됩니다.

## 실행

Node.js 24에서 실행합니다.

```bash
npm ci
npm start
```

기본 주소는 `http://localhost:3199`입니다. 다른 포트는 `PORT=3201 npm start`로 지정합니다.

## 검색과 결과

- 도서관별 결과를 SSE로 받아 먼저 도착한 책부터 표시합니다.
- 전자책·오디오북·실물도서, 이용 상태, 검색처로 필터링하고 관련도·이용 가능순으로 정렬합니다.
- 검색어와 필터·정렬은 주소에 저장됩니다. ‘검색 공유’ 링크를 열거나 새로고침해도 같은 조건이 복원됩니다.
- 실패한 검색처만 다시 조회하며, 먼저 받은 결과와 선택한 필터를 유지합니다.
- 최근의 정상 결과는 최대 2분간 재사용합니다. ‘새로 확인’은 캐시를 건너뛰고 현재 상태를 다시 조회합니다.
- 검색처 안내에서 각 결과의 확인 시각, 연결 오류, 일부 수집 여부를 확인할 수 있습니다.
- 검색 중지·연결 종료는 해당 요청을 취소합니다. 동일한 조회를 다른 사용자가 기다리는 경우 그 사용자의 조회는 계속됩니다.
- 같은 제목끼리 묶어 보여주며 판본·권차·부제는 임의로 통합하지 않습니다. 추가 소장처의 화면 요소는 펼칠 때 생성하고, 첫 표지가 실패하면 다른 검색처의 표지를 시도합니다.

대출·예약 가능 여부는 각 도서관의 상세 화면에서 최종 확인하세요. 로그인 정보나 비밀번호는 수집하지 않습니다. 최근 검색어는 해당 브라우저에만 저장되며 ‘지우기’로 삭제할 수 있습니다.

## API

| 경로 | 용도 |
| --- | --- |
| `/api/config/providers` | 지원 검색처와 외부 검색·로그인 주소 |
| `/api/search?q=쇳돌` | 전체 검색 결과 JSON |
| `/api/search/stream?q=쇳돌` | `start`, `provider`, `flow`, `done` SSE 이벤트 |

검색 API는 다음 옵션을 공통으로 지원합니다.

- `providers=eunpyeong-public,seoul`: 지정한 검색처만 조회합니다. 미등록 검색처는 400으로 거절합니다.
- `fresh=1`: 정상 결과 캐시를 건너뜁니다.
- 각 검색처 결과의 `checkedAt`은 실제 확인 시각, `cacheHit`은 최근 결과 재사용 여부입니다.
- 오류·불완전 응답은 캐시하지 않습니다. 캐시는 실행 인스턴스별이며 최대 256개 항목으로 제한됩니다.
- 부분 수집은 `partialResults`와 `warning`으로 표시하며, 실패를 미소장으로 판단하지 않습니다.

은평 검색은 개편된 정식 메뉴 경로를 사용합니다. HTTP 200 오류 페이지도 오류로 판정하고 전체 20초 제한 안에서 최대 3회 시도합니다. 0건 안내용 목록 행은 소장 건수에 포함하지 않습니다.

## 검증

```bash
npm test
# 같은 회귀 검사에 대한 기존 명령
npm run verify:regressions
```

고정된 공개 도서관 HTML과 제어된 HTTP 서버로 검색 파싱, 캐시·유효기간·중복 요청, 요청 취소, 선택 재조회, 오류·0건 구분, 공유 주소 복원을 검증합니다. 특정 책의 대출 상태가 매일 달라져도 회귀 검사는 영향을 받지 않습니다.

서버 실행 후 PC·모바일 화면을 검증합니다. Playwright Chromium을 설치하거나 `CHROMIUM_PATH`를 지정하세요. 관리 환경의 `/usr/bin/chromium`도 자동으로 사용할 수 있습니다.

```bash
npm run verify:ui
# 실제 외부 서비스 연결을 포함한 화면 검증
LIVE_VERIFY=1 BASE_URL=https://crawl-seoul-ebook-info-web-six.vercel.app npm run verify:ui
# 전체 검색처의 실제 연결 검사
npm run verify:providers
```

UI 검사는 1280·375·320px에서 성공·오류·0건, 선택 재조회, 필터 유지·주소 복원, 공유 복사 대체 화면, 키보드 모달 복귀, 추가 소장처 펼치기를 확인합니다. 실제 외부 서비스 검사는 도서관 점검이나 현재 소장 상태의 영향을 받을 수 있습니다.

개선 근거와 검증 범위는 [사이트 개선 기록](docs/site-improvements-2026-11-09.md)에 정리했습니다.

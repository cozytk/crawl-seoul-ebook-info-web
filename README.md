# ebook-local-web

서울 전자책/실물도서 검색 결과를 한 화면에서 판단하는 웹 도구입니다.

## 실행

```bash
npm install
npm run start
```

브라우저에서 `http://localhost:3199` 접속.

## 현재 구현

- 서울 전역 전자도서관(구 단위 포함) 14개 병렬 검색
  - 은평구립도서관 신규 공개 검색 API 연동
  - 서초구 전자도서관 추가 연동
- 밀리의서재 공개 검색 결과를 외부 구독형 서비스로 표시
  - 전자책과 오디오북 결과 분리 표시
  - 검색 노출만 있고 현재 열람할 수 없는 책은 볼 수 없음으로 판정
  - 계정 정보는 앱에 저장하지 않고, 검색 페이지/로그인 페이지 링크만 제공합니다.
- 서울도서관 구독형 상세 페이지처럼 `구독`으로 표시되는 자료는 바로 열람 가능한 후보로 판정
- 은평구공공도서관 실물도서 검색 시나리오
  - 대출가능 여부, 상호대차/책단비 가능 여부, 무인예약 가능 여부 표시
  - 은평뉴타운도서관 `상호대차진행자료`처럼 직접 대출은 아니어도 예약 가능한 상태는 예약 가능으로 판정
  - 대출가능 도서 안에서 대조꿈나무/대조동, 상호대차/무인예약 가능, 타 도서관 순으로 우선 배치
- 책 제목 기준 후보 파싱 및 상태 추정
  - 소장권수
  - 대출가능권수
  - 대출중권수
  - 예약/대기권수
- 예약 오판 방지 규칙 반영
  - `소장 1` + `예약 > 0` + `명시적 대출가능 없음` => 예약 상태 우선
- 화면 구조
  - `availability-os`: 전체 페이지 셸
  - `query-strip`: 검색 입력과 현재 검색 요약
  - `route-panel`: 사용자가 먼저 보는 판정 신호판
  - `primary-signal`: 지금 가능한 최우선 답을 크게 표시
  - `path-grid` / `path-cell`: 여섯 단계 판단 흐름
  - `evidence-feed` / `source-block` / `copy-line`: 도서관별 상세 근거
  - `source-index`: 지원 검색처 요약
- 판단 흐름
  1. 밀리의서재에서 바로 보기
  2. 대출형 전자도서관에서 빌리기
  3. 구독형 도서관에서 열람하기
  4. 은평구 공공도서관 직접 대출
  5. 은평구 공공도서관 직접 예약
  6. 어느 도서관이든 예약하기
- 로그인 보조
  - 각 도서관별 로그인 페이지 바로가기 제공

## 프론트엔드 결정

현재 배포 구조는 Express API와 `public/**` 정적 파일로 충분한 단일 페이지 앱입니다. 그래서 React/Vite/Next.js로 옮기지 않고, 기존 API와 SSE 검색 흐름은 유지한 채 HTML/CSS/vanilla JS 화면 전체를 새로 구성했습니다.

## 주의

- 교보/도서관 페이지 구조가 자주 바뀌므로 파싱 신뢰도는 사이트별로 달라질 수 있습니다.
- 실제 대출/예약 확정은 각 도서관 상세 페이지에서 최종 확인하세요.

## 검증

로컬 서버 실행 중 provider 연동을 확인합니다.

```bash
npm run verify:ui
npm run verify:providers
npm run verify:regressions
```
